```
cool-planck/
├── index.html            # 主頁面結構（整合 6 大核心專區、卡片網格、成果詳情、申請案明細表、彈窗）
├── css/
│   └── style.css         # 視覺樣式表（中研院 RCCI 品牌配色、PDF 兩欄排版、6 大專區專屬樣式）
├── js/
│   ├── rcci-content.js   # 官方網站全站真實內容資料庫（新聞、關於、計畫、設施、徵才）
│   ├── data.js           # 智財專利 PDF 官方摘要字典、設定參數與離線快照備援
│   ├── sync.js           # 專利資料讀取、跨分頁聚合與資料快顯引擎
│   └── app.js            # SPA 路由控制器、全站頁面渲染、即時搜尋過濾、專案與智財跨區連動
├── assets/
│   ├── rcci-logo.svg     # 中研院關鍵議題研究中心向量 SVG 標誌
│   └── favicon.svg       # 網站圖示
├── start-server.ps1      # 本機 HTTP 伺服器一鍵啟動腳本（http://localhost:8080）
└── README.md             # 專案完整技術與架構文件
```

### 🚀 開啟與使用方式

1. **直接雙擊開啟**：在檔案總管中雙擊 `index.html`，即可於任何瀏覽器暢順瀏覽所有內容與智財資料。
2. **本機伺服器**：在 PowerShell 執行 `.\start-server.ps1`，將啟動本機伺服器並自動開啟 `http://localhost:8080` 本機預覽。
3. **雲端部署**：純靜態現代化網頁架構，可直接發佈至 GitHub Pages、Vercel 或中研院院內 Web 伺服器。
