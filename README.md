2. **靜態與離線雙軌備援策略 (Local / GitHub Pages Fetch)**：

### 🚀 開啟與使用方式

1. **線上瀏覽**：直接點擊 [GitHub Pages 線上展示網址](https://tommy1114-commits.github.io/rcci-patents/) 即可瀏覽。
