本網頁專注於呈現中央研究院關鍵議題研究中心（RCCI）之**「智財與技術成果」**，已精簡移除上方全域導覽列，開啟網頁即直達核心成果專區：

#### 💡 智財與技術成果專區 (`#patents` & `#patent/{id}`)

* **視覺呈現與互動體驗**：
  * 三欄式技術成果卡片網格（包含技術領域 Badge、本院案件編號、專利名稱、提申國家旗幟、法律狀態）。
  * 成果詳情專頁：麵包屑路徑、PDF 官方技術摘要、各國專利申請佈局表格（US、TW、CN、JP、KR、EP、AU、CA、PCT）。
  * 右欄基本資訊卡片與「智財技轉處-案件技術資料」外部專屬連結（直接開啟中研院智財技轉處各案技術官方專屬頁面）。
* **資料驅動智財管理系統 (CSV 自動同步)**：

  * **本機與 GitHub 儲存庫雙軌支援**：支援讀取 `assets/RCCI-IP.csv`，自動解析並聚合為專利家族與各國案件明細。
  * **極速體驗**：支援 0 秒極速首屏載入、瀏覽器離線快照與資料更新來源/時間狀態標註。

#### 5. 🛠️ 設施服務 (`#facilities`)
* **6 大尖端共用研發設施**：
  1. 先進太陽能電池研發與量測設施 (Class AAA 太陽模擬器、EQE、手套箱)
  2. 量子晶片製程研發平台 QC-Fab (超導 Nb/Al/Ta 薄膜成長、EBL 電子束微影、ICP-RIE，已對外接受委託)
  3. 量子計算測試平台 (極低溫稀釋冷凍機 < 10 mK、微波多通道射頻讀出)
  4. 量子光電前瞻製程與精密分析設施 (低溫共焦 PL 光譜、TCSPC)
  5. 環境生地化參數測量設施 (營養鹽自動分析儀、同位素分析儀)
  6. 最小螢光光子通量顯微鏡 MINFLUX (1 至 3 奈米單分子奈米定位)
* **收費標準與繳款指引** (對齊 charge.php)：
  * 土地銀行南港分行 401 專戶匯款資訊、不收現金規範、統一開立收據/發票流程。
  * 整合中央研究院儀器預約系統快捷入口。
